# taotdm.com

a white field, one mark, six drifting pixels, tap a pixel to read it. one pixel holds the theme and sound settings

```sh
npm install
npm run dev
```

- text: `src/content.js`
- styles: `src/style.css`
- hand-drawn look: `src/hand.js` and `src/hand.css`. add `?hand` to the address for a picker of fonts and boil strength
- fonts: files in `public/fonts/`
- sounds: `src/sound.js`. files in `public/sfx/` take the place of the built-in sounds
- share card: `public/images/og-void.png`

pushes to `main` deploy through github pages
