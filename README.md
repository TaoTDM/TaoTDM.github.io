# taotdm.com

a white field, one mark, six drifting pixels, tap a pixel to read it. one pixel holds the theme and sound settings

```sh
npm install
npm run dev
```

- text: `src/content.js`
- styles: `src/style.css`
- sounds: files in `public/sfx/`
- share card: `public/images/og-void.png`

pushes to `main` deploy through github pages
